# Ethical & Responsible AI Reflection

## AI Tool Usage
This project used Claude (Anthropic) as a coding assistant for code generation, debugging, and documentation. All core design decisions — problem selection, dataset choice, model selection, and project direction — were made by the learner. AI was used similarly to how a developer might use GitHub Copilot or Stack Overflow.

## Data Ethics
- The dataset is publicly available and sourced from the World Happiness Report, a reputable academic source
- No personally identifiable information (PII) is present in the dataset
- Data represents country-level aggregates, not individuals

## Model Ethics
- The model predicts happiness scores for educational purposes only
- Predictions should not be used to make policy decisions without further validation
- The model may reflect biases present in the original survey methodology

## RAG Ethics
- All knowledge base sources are properly cited
- Content is grounded in peer-reviewed and institutional research
- No misinformation or fabricated content is included

## Responsible Use
- This app is for educational and exploratory purposes only
- Happiness is a complex human experience — no ML model can fully capture it
- Users should interpret predictions as estimates, not ground truth
